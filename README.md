# Air MIDI — Wireless MIDI System (2-in-1 Duplex)

**Air MIDI** — це універсальна двостороння бездротова система передачі MIDI-сигналів з наднизькою затримкою на базі мікроконтролерів **ESP32-C3**. Проєкт створено спеціально для гітарних педалбордів та процесорів ефектів, щоб позбутися MIDI-кабелів.

Обидва модулі системи розроблені для повністю автономної роботи, **живляться від Li-Ion / Li-Po акумулятора через підвищуючий DC-DC конвертер до стабільних 5В** і забезпечують повноцінний одночасний обмін даними в обидва боки (Duplex).

### 🎛️ Архітектура та логіка модулів:
1. **Air MIDI Board A (Основний передавач / Педалборд)**: Встановлюється на педалборд, підключається до контролера. Має фізичний тумблер вибору режиму. Дозволяє перемикатися між дуплекс-режимом (**ESP-NOW**) та (**BLE MIDI** для підключення до Windows/macOS/iOS).
2. **Air MIDI Board B (Приймач / Процесор)**: Фіксується біля процесора ефектів. Не має тумблерів та Bluetooth-стеку на рівні коду — плата завжди працює в режимі двостороннього зв'язку **ESP-NOW**, приймаючи команди від педалборду та повертаючи назад відповіді процесора (стан пресетів, темп тощо).

## 🚀 Особливості

* **Повноцінний дуплекс**: Одночасна передача даних в обидва боки в обох режимах (ESP-NOW та BLE). Процесор ефектів та педалборд-контролер можуть вільно спілкуватися між собою.
* **Максимальна стабільність радіо**: Перевірка тумблера відбувається один раз при старті в `setup()`. Радіомодуль ініціалізується монолітно, що повністю виключає помилки пам'яті чи паніку ядра чипа під час гри.
* **Повна автономність**: Робота від акумуляторів 18650 або Li-Po пакетів із вбудованою системою зарядки через USB та підвищенням до стабільних 5В.
* **Наднизька затримка (Latency)**: У режимі ESP-NOW затримка становить менше 2-5 мс, що є абсолютно невідчутним під час живого виконання.
* **Гібридна розмітка пам'яті**: Конфігурація `huge_app.csv` виділяє максимум простору, дозволяючи без проблем вмістити важкий BLE-стек на Board A.
* **Безпека репозиторію**: MAC-адреси плат винесені в окремий локальний файл конфігурації, який автоматично ігнорується Git.

## 📦 Список компонентів (Bill of Materials)

Оскільки система стала симетричною, **кожен із двох модулів** тепер містить однаковий повний набір вхідної та вихідної електроніки.

### 🧠 Мікроконтролери
* **ESP32-C3 (2 шт.)** — плати розробника (Development Board). Рекомендується використовувати компактні версії (наприклад, *ESP32-C3 SuperMini* або стандартний *DevKit*) з інтерфейсом USB Type-C.

### 🔋 Модулі живлення (Потрібно 2 однакові комплекти)
* **Li-Ion або Li-Po акумулятор (2 шт.)** — банки формату 18650 або плоскі Li-Po пакети на 3.7V.
* **Плата зарядки TP4056 із захистом (2 шт.)** — модуль із роз'ємом Type-C та вбудованим захистом від глибокого розряду акумулятора.
* **Модуль DC-DC Step-Up (Boost) конвертера (2 шт.)** — мініатюрна плата на чипі **MT3608** для генерації стабільних 5V з акумулятора.
* **LDO Стабілізатор на 3.3V (2 шт.)** — чипи **AP2112K-3.3** або **XC6206** для забезпечення стабільних 3.3V для мікроконтролерів (якщо відсутні якісні вбудовані на платах ESP32).
* **Вимикачі живлення (2 шт.)** — механічні тумблери ON/OFF для повного знеструмлення акумуляторів.

### 🔌 Електроніка обв'язки (Для КОЖНОГО з двох модулів)
* **Швидка оптопара 6N138** — 1 шт. (для вхідного порту MIDI IN).
* **Транзистор 2N7000** — 1 шт. (у вивідному корпусі TO-92 для вихідного порту MIDI OUT).
* **Гніздо MIDI Input та Output** — по 1 шт. (класичні 5-pin DIN або 3.5mm TRS джеки).
* **Діод 1N4148** — 1 шт. (захист входу оптопари).
* **Резистори**: 220 Ом (3 шт.), 4.7 кОм (1 шт.), 10 кОм (2 шт.).

### 🎛️ Додатково для Board A (Педалборд)
* **Тумблер режиму** — 1 шт. (для перемикання ESP-NOW / Bluetooth «на льоту» за рахунок замикання `GPIO 2` на `GND`).

## 🔌 Апаратне забезпечення (Hardware Specs)

Обидва модулі збираються за ідентичною схемою підключення портів до ESP32-C3:

### 1. Схема входу (MIDI IN -> RX GPIO20)
Завдяки стабільній лінії 5В від DC-DC конвертера, вхідний сигнал ізолюється швидкою оптопарою 6N138, а її вихід підтягується до безпечних 3.3В:
* `MIDI IN` гніздо (Pin 4) -> Резистор 220 Ом -> Анод оптопари (Pin 2).
* `MIDI IN` гніздо (Pin 5) -> Катод оптопари (Pin 3).
* *Між Pin 2 та Pin 3 оптопари встановлюється діод 1N4148 (анодом до Pin 3, катодом до Pin 2).*
* Pin 8 ($V_{CC}$) оптопари -> до лінії **5V** (від MT3608).
* Pin 5 (GND) оптопари -> до **GND**.
* Pin 7 оптопари -> Резистор 10 кОм -> до **GND** (для прискорення закриття).
* Pin 6 ($V_O$) оптопари -> Пін `RX` (GPIO20) ESP32-C3 **ТА** через резистор 4.7 кОм до **3.3V**.

### 2. Схема виходу (TX GPIO21 -> MIDI OUT)
Для повноцінного розгону сигналу `TX` з 3.3В до чесних 5В використовується транзистор 2N7000 (корпус TO-92):
* Пін `TX` (GPIO21) ESP32-C3 -> Source (Витік / Ніжка 1) транзистора 2N7000.
* Gate (Затвор / Ніжка 2) транзистора -> до лінії **3.3V**.
* Drain (Стік / Ніжка 3) транзистора -> підтягується через резистор 10 кОм до лінії **5V**, а також через захисний резистор 220 Ом іде на `MIDI OUT` гніздо (Pin 5).
* Лінія **5V** через другий захисний резистор 220 Ом іде на `MIDI OUT` гніздо (Pin 4).
* `MIDI OUT` гніздо (Pin 2) -> до **GND** (екран кабелю).

## 🛠️ Налаштування та прошивка (PlatformIO)

Проєкт реалізовано на базі **PlatformIO** з використанням роздільних середовищ для кожної плати.

### Крок 1: Визначення MAC-адрес плат
1. Підключіть першу плату до ПК, виберіть середовище `env:get_mac` та запустіть **Upload and Monitor**. Скопіюйте її MAC-адресу.
2. Повторіть процедуру для другої плати.

### Крок 2: Створення локального файлу конфігурації
Створіть файл `include/mac_address.h` та впишіть туди отримані адреси обох пристроїв (цей файл ігнорується Git):

```cpp
#pragma once

// MAC-адреси ваших плат (замініть на власні реальні дані)
const uint8_t MAC_MODULE_A[] = {0x4C, 0x75, 0x25, 0xAA, 0xBB, 0x01};
const uint8_t MAC_MODULE_B[] = {0x4C, 0x75, 0x25, 0xAA, 0xBB, 0x02};
```

### Крок 3: Завантаження прошивки
Для прошивки плат використовуйте бічну панель інструментів PlatformIO (іконка з головою мурахи) або вбудований термінал VS Code.
```pio run -e transmitter -t upload```
```pio run -e receiver -t upload```

## 🎹 Налаштування Windows (Режим BLE MIDI)
Якщо ви використовуєте Air MIDI з ПК у режимі Bluetooth, для мінімальної затримки та коректної роботи в DAW (Reaper, Neural DSP, Cubase тощо) виконайте такі кроки:
1. Перемкніть тумблер на пристрої в режим BLE та увімкніть пристрій (GPIO 2 замкнено на GND) — плата запустить Bluetooth.
2. Спаруйте пристрій Air MIDI Alpha через стандартне меню Bluetooth у Windows.
3. Встановіть утиліту loopMIDI (для створення віртуальних MIDI-портів у системі) та драйвер KORG BLE-MIDI Driver (він дозволяє Windows бачити BLE пристрої як класичний MIDI-інтерфейс із низьким рівнем Latency).
