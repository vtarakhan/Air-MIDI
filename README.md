# Air MIDI — Wireless MIDI System (2-in-1)

**Air MIDI** — це бездротова система передачі MIDI-сигналів з наднизькою затримкою на базі мікроконтролерів **ESP32-C3**. Проєкт створено спеціально для гітарних педалбордів та процесорів ефектів, щоб позбутися MIDI-кабелів на сцені та в студії.

Обидва модулі системи розроблені для повністю автономної роботи та **живляться від Li-Ion / Li-Po акумулятора через підвищуючий DC-DC конвертер до стабільних 5В**.

### 🎛️ Архітектура системи:
1. **Air MIDI Transmitter (Передавач)**: Встановлюється на педалборд, підключається до `MIDI OUT` вашого контролера. Має тумблер вибору режиму: **ESP-NOW** (для сцени, миттєвий зв'язок з приймачем) або **BLE MIDI** (для студії, пряме підключення до Windows/macOS/iOS).
2. **Air MIDI Receiver (Приймач)**: Фіксується біля процесора ефектів, приймає дані по радіоканалу ESP-NOW та віддає їх безпосередньо в `MIDI IN` процесора.

## 🚀 Особливості

* **Повна автономність**: Робота від акумуляторів 18650 або Li-Po пакетів із вбудованою системою зарядки через USB та підвищенням до 5В.
* **Гібридний режим 2-в-1**: Швидке перемикання однією кнопкою/тумблером між концертним (ESP-NOW) та студійним (Bluetooth) режимами.
* **Наднизька затримка (Latency)**: У режимі ESP-NOW затримка становить менше 2-5 мс, що є абсолютно невідчутним під час живого виконання.
* **Гібридна розмітка пам'яті**: Конфігурація `huge_app.csv` дозволяє вмістити важкий BLE-стек у пам'ять ESP32-C3, залишаючи максимум місця для коду.
* **Безпека репозиторію**: MAC-адреса приймача винесена в окремий конфігураційний файл, який автоматично ігнорується Git.

## 📦 Список компонентів (Bill of Materials)

Для повної збірки системи (Передавач + Приймач) вам знадобиться наступне залізо:

### 🧠 Мікроконтролери
* **ESP32-C3 (2 шт.)** — плати розробника (Development Board). Рекомендується використовувати компактні версії (наприклад, *ESP32-C3 SuperMini* або стандартний *DevKit*) з інтерфейсом USB Type-C.

### 🔋 Модулі живлення (Потрібно 2 однакові комплекти)
* **Li-Ion або Li-Po акумулятор (2 шт.)** — банки формату 18650 або плоскі Li-Po пакети на 3.7V (оптимально від 500 до 1200 mAh).
* **Плата зарядки TP4056 із захистом (2 шт.)** — модуль із роз'ємом Type-C та вбудованим захистом від глибокого розряду акумулятора.
* **Модуль DC-DC Step-Up (Boost) конвертера (2 шт.)** — мініатюрна плата на чипі **MT3608** для генерації стабільних 5V з акумулятора для обох пристроїв.
* **LDO Стабілізатор на 3.3V (2 шт.)** — чипи **AP2112K-3.3** або **XC6206** для забезпечення стабільних 3.3V для мікроконтролерів (якщо відсутні якісні вбудовані на платах ESP32).
* **Вимикачі живлення (2 шт.)** — механічні тумблери ON/OFF для повного знеструмлення акумуляторів.

### 🔌 Електроніка для Air MIDI Transmitter (Передавач)
* **Швидка оптопара 6N138** — 1 шт. (класична оптопара, що стабільно та швидко працює завдяки лінії 5В від DC-DC).
* **Гніздо MIDI Input** — 1 шт. (класичний 5-pin DIN або 3.5mm TRS джек, залежно від виходу вашого педалборду).
* **Тумблер режиму** — 1 шт. (для перемикання ESP-NOW / Bluetooth за рахунок замикання `GPIO 2` на `GND`).
* **Діод 1N4148** — 1 шт.
* **Резистори**: 220 Ом (1 шт.), 4.7 кОм (1 шт.), 10 кОм (1 шт. для Pin 7 оптопари).

### 🎛️ Електроніка для Air MIDI Receiver (Приймач)
* **Транзистор 2N7000** — 1 шт. (у вивідному корпусі TO-92 для точного та надійного узгодження логіки виходу TX з 3.3V до 5V).
* **Штекер/Гніздо MIDI Output** — 1 шт. (5-pin DIN або 3.5mm TRS для підключення у процесор ефектів).
* **Резистори**: 10 кОм (1 шт. для підтяжки лінії), 220 Ом (2 шт. захисні на вихідні піни MIDI).

## 🔌 Апаратне забезпечення & Зв'язок (Hardware Specs)

### 1. Схема входу (Transmitter)
Завдяки наявності постійної лінії 5В від DC-DC конвертера, вхідний MIDI-сигнал ізолюється класичною швидкою оптопарою 6N138. Вихід оптопари підтягується до безпечних для мікроконтролера 3.3В:
* `MIDI OUT` педалборду (Pin 4) -> Резистор 220 Ом -> Анод оптопари (Pin 2).
* `MIDI OUT` педалборду (Pin 5) -> Катод оптопари (Pin 3).
* *Між Pin 2 та Pin 3 оптопари встановлюється діод 1N4148 (анодом до Pin 3, катодом до Pin 2) для захисту від зворотної полярності.*
* Pin 8 ($V_{CC}$) оптопари -> до лінії **5V** (від MT3608).
* Pin 5 (GND) оптопари -> до **GND**.
* Pin 7 оптопари -> Резистор 10 кОм -> до **GND** (для прискорення закриття транзистора).
* Pin 6 ($V_O$) оптопари -> Пін `RX` ESP32-C3 **ТА** через резистор 4.7 кОм до **3.3V**.

### 2. Схема виходу (Receiver)
Для того, щоб будь-який процесор ефектів чітко розпізнавав команди, сигнал з піна `TX` піднімається до чесних 5В за допомогою транзистора 2N7000 (у вивідному корпусі TO-92):
* Пін `TX` ESP32-C3 -> Source (Витік / Ніжка 1) транзистора 2N7000.
* Gate (Затвор / Ніжка 2) транзистора -> до лінії **3.3V**.
* Drain (Стік / Ніжка 3) транзистора -> підтягується через резистор 10 кОм до лінії **5V** (від MT3608), а також через захисний резистор 220 Ом іде на `MIDI IN` процесора (Pin 5).
* Лінія **5V** через другий захисний резистор 220 Ом іде на `MIDI IN` процесора (Pin 4).
* `MIDI IN` процесора (Pin 2) -> до **GND** (екран кабелю).

## 🛠️ Налаштування та прошивка (PlatformIO)

Проєкт реалізовано на базі **PlatformIO** з використанням роздільних середовищ (`env`).

### Крок 1: Визначення MAC-адреси приймача
1. Підключіть майбутню плату **Приймача** до ПК через USB.
2. У PlatformIO виберіть та запустіть таск `env:get_mac` (**Upload and Monitor**).
3. Скопіюйте унікальну MAC-адресу, яку плата виведе у консоль.

### Крок 2: Створення локального файлу конфігурації
Створіть файл `include/mac_address.h` у своєму проєкті та вставте туди скопійовану адресу приймача:

```cpp
#pragma once
#include <Arduino.h>

// Реальна MAC-адреса вашого Air MIDI Receiver
const uint8_t RECEIVER_MAC_ADDRESS[] = {0x4C, 0x75, 0x25, 0xAA, 0xBB, 0xCC};
```

### Крок 3: Завантаження прошивки
Для прошивки плат використовуйте бічну панель інструментів PlatformIO (іконка з головою мурахи) або вбудований термінал VS Code.
```pio run -e transmitter -t upload```
```pio run -e receiver -t upload```

## 🎹 Налаштування Windows (Режим BLE MIDI)
Якщо ви використовуєте Air MIDI з ПК у режимі Bluetooth, для мінімальної затримки та коректної роботи в DAW (Reaper, Neural DSP, Cubase тощо) виконайте такі кроки:
1. Перемкніть тумблер на пристрої в режим BLE (замкнено на GND) та увімкніть живлення.
2. Спаруйте пристрій Air MIDI через стандартне меню Bluetooth у Windows.
3. Встановіть утиліту loopMIDI (для створення віртуальних MIDI-портів у системі) та драйвер KORG BLE-MIDI Driver (він дозволяє Windows бачити BLE пристрої як класичний MIDI-інтерфейс із низьким рівнем Latency).
