# Air MIDI — Wireless MIDI System (2-in-1)

**Air MIDI** — бездротова система передачі MIDI-сигналів з наднизькою затримкою на базі мікроконтролерів **ESP32-C3**. Проєкт створено спеціально для гітарних педалбордів та процесорів ефектів, щоб позбутися MIDI-кабелів на сцені та в студії.

Обидва модулі системи розроблені для повністю автономної роботи та **живляться від Li-Ion / Li-Po акумуляторів (3.7V)**.

### 🎛️ Архітектура системи:
1. **Air MIDI Transmitter (Передавач)**: Встановлюється на педалборд, підключається до `MIDI OUT` вашого контролера. Має тумблер вибору режиму: **ESP-NOW** (для сцени, миттєвий зв'язок з приймачем) або **BLE MIDI** (для студії, пряме підключення до Windows/macOS/iOS).
2. **Air MIDI Receiver (Приймач)**: Фіксується біля процесора ефектів, приймає дані по радіоканалу ESP-NOW та віддає їх безпосередньо в `MIDI IN` процесора.

---

## 🚀 Особливості

* **Повна автономність**: Робота від акумуляторів 18650 або Li-Po пакетів із вбудованою системою зарядки через USB.
* **Гібридний режим 2-в-1**: Швидке перемикання однією кнопкою/тумблером між концертним (ESP-NOW) та студійним (Bluetooth) режимами.
* **Наднизька затримка (Latency)**: У режимі ESP-NOW затримка становить менше 2-5 мс, що є абсолютно невідчутним під час живого виконання.
* **Гібридна розмітка пам'яті**: Конфігурація `huge_app.csv` дозволяє вмістити важкий BLE-стек у пам'ять ESP32-C3, залишаючи максимум місця для коду.
* **Безпека репозиторію**: MAC-адреса приймача винесена в окремий конфігураційний файл, який автоматично ігнорується Git.

## 📦 Список компонентів (Bill of Materials)

Для повної збірки системи (Передавач + Приймач) вам знадобиться наступне залізо:

### 🧠 Мікроконтролери
* **ESP32-C3 (2 шт.)** — плати розробника (Development Board). Рекомендується використовувати компактні версії (наприклад, *ESP32-C3 SuperMini* або стандартний *DevKit*) з інтерфейсом USB Type-C.

### 🔋 Модулі живлення (Потрібно 2 однакові комплекти)
* **Li-Ion або Li-Po акумулятор (2 шт.)** — банки формату 18650 або плоскі Li-Po пакети на 3.7V (оптимально від 500 до 1200 mAh).
* **Плата зарядки TP4056 із захистом (2 шт.)** — модуль із роз'ємом Type-C та вбудованим захистом від глибокого розряду акумулятора.
* **LDO Стабілізатор на 3.3V (2 шт.)** — чипи **AP2112K-3.3** або **XC6206** для забезпечення стабільних 3.3V для мікроконтролерів.
* **Вимикачі живлення (2 шт.)** — механічні тумблери ON/OFF для повного знеструмлення акумуляторів.

### 🔌 Електроніка для Air MIDI Transmitter (Передавач)
* **Швидка оптопара H11L1 (або 6N137)** — 1 шт. (необхідна для стабільної роботи цифрової логіки на напрузі 3.3В).
* **Гніздо MIDI Input** — 1 шт. (класичний 5-pin DIN або 3.5mm TRS джек, залежно від виходу вашого педалборду).
* **Тумблер режиму** — 1 шт. (для перемикання ESP-NOW / Bluetooth за рахунок замикання `GPIO 2` на `GND`).
* **Діод 1N4148** — 1 шт.
* **Резистори**: 220 Ом (1 шт.), 4.7 кОм (1 шт.).

### 🎛️ Електроніка для Air MIDI Receiver (Приймач)
* **Модуль DC-DC Step-Up (Boost) конвертера** — 1 шт. (мініатюрна плата на чипі **MT3608** для генерації стабільних 5V).
* **Транзистор BSS138** — 1 шт. (N-канальний польовий транзистор для узгодження логіки `TX` з 3.3V до 5V).
* **Штекер/Гніздо MIDI Output** — 1 шт. (5-pin DIN або 3.5mm TRS для підключення у процесор ефектів).
* **Резистори**: 10 кОм (1 шт.), 220 Ом (2 шт.).

## 🔌 Апаратне забезпечення & Живлення (Hardware)

Оскільки система повністю мобільна і працює від акумулятора **3.7V (Li-Po / Li-Ion)**, схеми узгодження та живлення оптимізовані для низьковольтної логіки.

### 🔋 Модуль живлення (однаковий для обох пристроїв)
Для кожного модуля знадобиться:
* Акумулятор 3.7V (наприклад, Li-Ion 18650 або компактний Li-Po пакет).
* Контролер заряду **TP4056** із захистом (Protection Circuit) для безпечної зарядки через USB Type-C.
* Енергоефективний LDO-стабілізатор на **3.3V** (наприклад, **XC6206** або **AP2112K**), який живить ESP32-C3 та периферію від акумулятора.

---

### 1. Air MIDI Transmitter (Передавач на педалборді)
Через відсутність стабільної лінії 5В при роботі від акумулятора, для читання `MIDI IN` замість застарілої оптопари 6N138 використовується сучасна швидка оптопара, що чесно працює від 3.3В.

* **Рекомендована оптопара**: **H11L1** (з тригером Шмітта) або високошвидкісна **6N137** (3.3V сумісна версія).
* **Схема входу**: `MIDI OUT` педалборду ➡️ Оптопара H11L1 (Живлення від лінії 3.3V після LDO) ➡️ Пін `RX` ESP32-C3.
* **Тумблер режимів**: Підключається між `GPIO 2` та `GND`. 
  * `HIGH` (відкритий, працює внутрішня підтяжка) = Режим **ESP-NOW**.
  * `LOW` (тумблер замкнений) = Режим **BLE MIDI**.

---

### 2. Air MIDI Receiver (Приймач біля процесора)
Для того, щоб процесор ефектів чітко розпізнавав команди, сигнал з 3.3-вольтового піна `TX` мікроконтролера потрібно підняти до стандартних 5В, які вимагає класичний MIDI-вхід.

* **Рішення**: Оскільки пристрій автономний, для отримання 5В використовується маленький і дешевий модуль **DC-DC Step-Up (Boost) конвертера** (наприклад, на чіпі MT3608), який піднімає напругу з акумулятора до стабільних 5В.
* **Схема виходу**: Пін `TX` ESP32-C3 ➡️ Конвертер рівнів на транзисторі **BSS138** ( Gate підключено до 3.3V, Drain підтягнуто через 10 кОм до згенерованих 5V) ➡️ Резистор 220 Ом ➡️ `MIDI IN` (Pin 5) вашого процесора.

## 🛠️ Налаштування та прошивка (PlatformIO)

Проєкт реалізовано на базі **PlatformIO** з використанням роздільних середовищ (`env`).

### Визначення MAC-адреси приймача
1. Підключіть майбутню плату **Приймача** до ПК через USB.
2. У PlatformIO виберіть та запустіть таск `env:get_mac` (**Upload and Monitor**).
3. Скопіюйте унікальну MAC-адресу, яку плата виведе у консоль.
4. Створіть файл `include/mac_address.h` у своєму проєкті та вставте туди скопійовані байти:

```cpp
#pragma once
#include <Arduino.h>

// Реальна MAC-адреса вашого Air MIDI Receiver
const uint8_t RECEIVER_MAC_ADDRESS[] = {0x00, 0x00, 0x00, 0x00, 0x00, 0x00};
```
